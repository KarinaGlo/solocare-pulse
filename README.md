# SoloCare Pulse

Near-real-time Public Perception Index for 19 Hospitals in Surakarta.

## Project Overview

SoloCare Pulse is a data engineering and NLP project to collect,
process, analyze, and visualize public reviews and perceptions
of hospitals in Surakarta.

## Main Components

- Data Ingestion
- Stream Processing
- Sentiment Analysis
- Data Warehouse
- API
- Dashboard
- Monitoring
